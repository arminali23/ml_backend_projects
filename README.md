# ML Backend Projects

A collection of small-to-medium machine learning backend projects built with Python and FastAPI.

## Projects

### 1. House Price Prediction API

- Regression-based ML model
- FastAPI backend
- Model training separated from serving

### 2. Spam / Ticket Classifier API

- Text classification
- scikit-learn pipeline
- REST API + Swagger UI

### 3. Async Ticket Classifier

- Job-based inference
- BackgroundTasks
- SQLite persistence
- Polling-based web UI

## Purpose

This repository is intended for learning and demonstrating:

- ML model training vs serving separation
- Backend API design for ML systems
- Clean project structuring
